#**Backducks-Ring-Card-**
![Logo](Logo.jpeg)
Este es un sistema enfocado en la gestión y control de tarjetas bancarias, tanto de Crédito como de Débito. El objetivo principal de esta aplicación web es centralizar los estados de cuenta y ofrecer recordatorios automáticos para que el usuario recuerde pagar sus tarjetas de crédito a tiempo, evitando recargos o intereses moratorios.
Esto debido a que actualmente, las tarjetas de crédito y débito forman parte de la vida cotidiana de muchas personas, ya que permiten realizar compras, pagos de servicios, transacciones digitales y financiamientos de manera rápida y sencilla. Se ha identificado que muchas personas presentan dificultades para recordar las fechas límite de pago, los montos pendientes, las compras realizadas o incluso la cantidad de tarjetas que poseen activas. Esta situación provoca retrasos en los pagos, intereses adicionales, descontrol en los gastos realizados con base en pagos o compras y afectaciones en el historial crediticio de los usuarios.
El software está diseñado para ser accesible, eficiente y fácil de utilizar, permitiendo que cualquier persona pueda mejorar el control de sus pagos y evitar cargos innecesarios por atrasos. Con este proyecto se busca fomentar una mejor organización económica y ofrecer una solución tecnológica útil para la administración de finanzas personalesn.   


##  Objetivo principal
Desarrollar una herramienta digital segura, práctica y accesible que facilite el seguimiento de gastos, la gestión de fechas límite mediante recordatorios automáticos y la generación de reportes financieros mensuales en formato Excel para una mejor organización económica.

##  Tecnologías utilizadas
* **Lenguaje:** Java 
* **Interfaz Gráfica:** Java Swing ( mediante FlatLaf)
* **Base de Datos:** PostgreSQL
* **Control de Versiones:** Git y GitHub

La aplicación está diseñada para ser intuitiva y fácil de usar. Sus funciones principales son:

**Registro de Tarjetas:**Permite dar de alta las tarjetas ingresando datos clave como el límite de crédito, saldo actual, fecha de corte y fecha límite de pago.
**Control de Movimientos:**Pueder registrar los ingresos o consumos diarios para mantener saldos actualizados automáticamente.
**Sistema de Alertas:** La interfaz mostrará avisos  claros antes de que lleguen las fechas de vencimiento para  no olvidar los pagos.
